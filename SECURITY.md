# Security and responsible use

VIGIL is intended for public-source, defensive and authorized investigations.

## Supported scope

- public brand/account impersonation;
- misinformation and coordinated-behavior analysis from public datasets;
- corporate threat intelligence;
- passive asset discovery for domains and organizations you are permitted to assess;
- academic, journalistic and verification work using lawful public sources.

## Out of scope

Do not add collectors or features for:

- credential theft or password attacks;
- phishing or malware delivery;
- bypassing authentication or access controls;
- leaked credential databases;
- private data brokers or residential-address discovery;
- stalking or automated harassment;
- offensive social engineering;
- automated influence operations;
- identifying private people through biometric recognition.

Collection modules should preserve provenance, rate-limit requests, prefer passive/public interfaces and follow provider terms.

## Vulnerability reports

If a VIGIL vulnerability contains exploitable details, use a GitHub private security advisory rather than a public issue.
